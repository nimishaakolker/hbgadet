# Task Manager App

A full-featured Task Manager web app built with React.js, 
connecting to a REST API with complete CRUD operations.

## Live Demo
View Live App (https://hbgadet.vercel.app/)

## Features
- View all tasks fetched from REST API
- Create new tasks with form validation
- Edit existing tasks via modal
- Delete tasks with confirmation dialog
- Toggle task status (Completed/Pending)
- Search tasks by title in real-time
- Filter by All / Completed / Pending
- Toast notifications for all actions
- Loading spinner and error states
- Fully responsive (mobile + desktop)

## Tech Stack
- React.js (Functional Components + Hooks)
- Axios
- Tailwind CSS
- Context API + Custom Hook (useTasks)
- JSONPlaceholder API
